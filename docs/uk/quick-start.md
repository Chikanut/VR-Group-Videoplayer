# Швидкий старт

Після цього гайду одна панель керування запускає відео уроку на всіх окулярах класу.

## Що потрібно

- окуляри Meta Quest для кожного учня (перевірено Quest 3 / 3S)
- ПК з Windows для першого налаштування через USB і кабель USB-C
- пристрій викладача для уроків: той самий ПК або телефон/планшет Android
- мережа Wi-Fi, до якої підключені ПК і всі окуляри; інтернет не потрібен
- файли з [GitHub Releases](https://github.com/Chikanut/VR-Group-Videoplayer/releases/latest):
  `VRClassroomPlayer-Quest.apk`, `QuestDeployManager.exe` і одна панель керування
  (`VRClassroomControlPanel-Windows.exe` або `VRClassroomControlPanel-Android.apk`)

## 1. Один раз підготуйте кожні окуляри (близько 2 хвилин на окуляри)

1. Увімкніть **режим розробника** для окулярів у застосунку Meta Horizon на телефоні.
2. Запустіть `QuestDeployManager.exe` на ПК. Він відкривається в окремому вікні.
3. У розділі **Додатки (APK)** додайте `VRClassroomPlayer-Quest.apk`.
4. У розділі **Wi-Fi** додайте мережу класу.
5. Підключіть окуляри через USB, надягніть їх і дозвольте налагодження USB (позначте *Завжди дозволяти*).
6. У розділі **Окуляри** натисніть **Розгорнути**.

Розгортання встановлює плеєр, налаштовує автозапуск і тихі оновлення та підключає окуляри до Wi-Fi. Повторіть для кожних окулярів; через USB-хаб можна підключити кілька одночасно.

Детальніше: [Deploy Manager](deploy-manager.md).

## 2. Запустіть панель керування

- **Windows:** запустіть `VRClassroomControlPanel-Windows.exe`. Пульт відкриється в браузері за адресою `http://localhost:8000`. Коли Windows запитає, дозвольте доступ у брандмауері для *приватних* мереж.
- **Android:** встановіть і відкрийте `VRClassroomControlPanel-Android.apk`.

Окуляри самі знаходять панель за кілька секунд і з'являються плитками.

Детальніше: [Налаштування панелі керування](setup-control-panel.md).

## 3. Додайте відео уроку

1. Відкрийте **Налаштування → Відео уроку** і натисніть **+ Додати відео** для кожного відео. Вкажіть лише назву файлу, наприклад `lesson01.mp4`, і виберіть `360` або `2D`.
2. Покладіть файли відео в одну папку на ПК і вкажіть її в **Налаштування → Система → Папка з відео (бібліотека)**.
3. Натисніть **Зберегти зміни**, поверніться на пульт і натисніть **Синхронізувати відео**. Окуляри завантажать відео по Wi-Fi.

Відео також можна скопіювати через USB у Deploy Manager. Детальніше: [Підготовка відео](prepare-videos.md).

## 4. Проведіть урок

Коли на плитках написано **Вимоги виконано**, виберіть відео і натисніть **Відтворити всі**.

Детальніше: [Щоденне використання](daily-use.md).

## Якщо щось не працює

- окуляри не з'являються: [Мережа та усунення проблем](networking-troubleshooting.md)
- на плитці написано **Плеєр не відкривається**: [Deploy Manager → Відновити](deploy-manager.md#відновити-окуляри-що-зависли)
- бракує відео: [Підготовка відео](prepare-videos.md)
