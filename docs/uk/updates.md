# Оновлення

Усі частини оновлюються з [GitHub Releases](https://github.com/Chikanut/VR-Group-Videoplayer/releases/latest). Інтернет потрібен лише комп'ютеру з панеллю керування або Deploy Manager, окулярам — ні.

## Панель керування

Відкрийте **Налаштування → Оновлення**. Там видно версію панелі, версії плеєра на окулярах і останній реліз з описом. Панель перевіряє оновлення один раз при запуску; вимкніть **Перевіряти оновлення при запуску**, щоб вона ніколи не зверталася до GitHub. **Перевірити зараз** перевіряє ще раз.

![Налаштування → Оновлення](../assets/screenshots/settings-updates-uk.png)

- **Windows exe:** **Завантажити і перезапустити** завантажує новий `VRClassroomControlPanel-Windows.exe`, замінює запущений файл і запускає його знову. `config.json` і назви окулярів залишаються.
- **Android і запуск із коду:** **Відкрити реліз** відкриває сторінку релізу; новий файл встановіть вручну.

Коли виходить нова версія, панель показує банер угорі кожної сторінки.

## Плеєр на окулярах

**Налаштування → Оновлення → Оновити всі окуляри** завантажує APK плеєра з релізу на ПК і надсилає його на всі підключені окуляри. Кожні окуляри завантажують його по Wi-Fi і встановлюють без запитань, навіть коли плеєр закритий. Плитки показують прогрес (`Оновлення плеєра: Завантаження 62%`).

Щоб надіслати свій APK, вкажіть його в **Налаштування → Система → Шлях до APK плеєра** і натисніть **Оновити плеєри**.

Для тихого оновлення потрібно:

- одноразове налаштування через Deploy Manager;
- щоб усі APK були підписані тим самим ключем; для релізів це так.

Окуляри, де вже стоїть цей APK, пропускають оновлення.

## Deploy Manager

Відкрийте **Оновлення** в Deploy Manager:

- **Завантажити і перезапустити** оновлює сам Deploy Manager;
- **Завантажити APK плеєра** ставить новий плеєр у список APK для наступного розгортання через USB.

## Які версії сумісні

Панель працює і зі старими плеєрами, але нові функції потребують свіжого плеєра:

| Функція | Версія плеєра |
|---|---|
| Агент, що завжди на зв'язку; відкрити/закрити плеєр; відео по Wi-Fi | 1.9.0+ |
| Оточення в окулярах | 1.9.1+ |
| Виявлення «Плеєр не відкривається» і захист від магазину | 1.9.2+ |

Надійніше за все оновити окуляри до тієї ж версії, що й панель.
