# Огляд

VR Group Videoplayer запускає одне відео уроку на всьому класі окулярів Meta Quest з одного пристрою викладача. Система створена для шкіл, лабораторій, музеїв і навчальних класів, працює в локальній мережі без інтернету і не потребує програмування.

## Складові

| Частина | Де працює | Що робить |
|---|---|---|
| **Плеєр** (`VRClassroomPlayer-Quest.apk`) | на кожних окулярах | відтворює відео; його агент тримає окуляри на зв'язку, навіть коли плеєр закритий чи окуляри сплять |
| **Панель керування** (`VRClassroomControlPanel-Windows.exe` / `-Android.apk`) | ПК або планшет викладача | пульт: показує всі окуляри, надсилає команди, відео й оновлення по Wi-Fi |
| **Deploy Manager** (`QuestDeployManager.exe`) | ПК з Windows, USB | перше налаштування, відновлення і відкат окулярів |

## Що можна робити

- бачити всі окуляри зі станом, зарядом, відео і прогресом;
- відтворювати, ставити на паузу, продовжувати, зупиняти, перемотувати і центрувати — для класу або вибраних окулярів;
- встановлювати гучність для всіх або одних окулярів;
- присипляти клас і будити його по Wi-Fi;
- відкривати, перезапускати і закривати плеєр, вмикати і вимикати автозапуск;
- надсилати відео уроку і нові версії плеєра по Wi-Fi;
- задавати вигляд кімнати очікування і системні налаштування Android для всіх окулярів;
- налаштовувати, відновлювати і прибирати окуляри через USB;
- оновлювати все з GitHub.

## Типовий урок

1. Окуляри один раз налаштовують через USB у Deploy Manager.
2. Викладач запускає панель керування; окуляри з'являються самі.
3. **Синхронізувати відео** надсилає відео уроку на всі окуляри.
4. **Відтворити всі** запускає відео для класу; **Центрувати всі** повертає його туди, куди дивляться учні.
5. **Приспати всі** наприкінці, **Розбудити всі** наступного разу.

## Обмеження

- відео відтворюються з пам'яті окулярів (`/sdcard/Movies/`), а не стрімляться;
- панель посилається на відео за назвою файлу;
- 360° моно і пласкі 2D відео; стерео 3D заплановано.
