# Налаштування Quest player

Плеєр — це застосунок на кожних окулярах. Він відтворює відео, а невеликий агент у ньому тримає окуляри на зв'язку з панеллю керування, навіть коли плеєр закритий або окуляри сплять.

## Рекомендовано: Deploy Manager

Встановлюйте плеєр через [Deploy Manager](deploy-manager.md). Крім встановлення APK, він робить одноразове налаштування, потрібне для тихих оновлень, автозапуску і системних налаштувань, і підключає окуляри до Wi-Fi класу.

1. Увімкніть режим розробника для окулярів (застосунок Meta Horizon на телефоні).
2. Додайте `VRClassroomPlayer-Quest.apk` у **Додатки (APK)**, а мережу класу — у **Wi-Fi**.
3. Підключіть окуляри через USB, дозвольте налагодження USB і натисніть **Розгорнути**.

## Встановлення APK вручну

`adb install VRClassroomPlayer-Quest.apk` або SideQuest теж працюють, але тоді плеєр:

- не зможе тихо оновлюватися;
- може не запускатися сам після перезавантаження;
- не зможе застосовувати системні налаштування окулярів.

Пізніше достатньо один раз зробити розгортання, щоб це додати.

## Що видно в окулярах

Поки відео не грає, плеєр показує кімнату очікування з HUD:

- угорі ліворуч — номер або назва окулярів;
- стан і адреса панелі керування;
- унизу ліворуч — чи ввімкнено автозапуск.

Кімната очікування — це модель логотипа на бордовому небі або ваш колір і зображення з **Налаштування → Оточення в окулярах**.

## Автозапуск

З увімкненим автозапуском плеєр сам відкривається після пробудження чи перезавантаження окулярів і повертається, якщо його закрили. Для класу це зазвичай те, що потрібно. Щоб використати окуляри для чогось іншого:

- вимкніть автозапуск для одних окулярів (вікно пристрою), для вибраних або для всього класу (пульт) чи в Deploy Manager;
- або в самих окулярах, поки відео не грає, утримуйте щипок вказівними пальцями обох рук 3 секунди.

Автозапуск залишається вимкненим і після перезавантаження, доки його знову не ввімкнути.

## Пошук панелі керування

Окуляри запам'ятовують адресу панелі. У новій мережі вони самі шукають у локальній підмережі `/24` порт 8000; панель теж повідомляє всім окулярам, які бачить, де вона. В окулярах нічого вводити не треба.
